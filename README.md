# DayMate

Персональный помощник: события дня, приём лекарств, календарь, привычки и статистика.
Этап 1 — рабочая веб-версия (React + TypeScript + Tailwind CSS + Vite), данные хранятся локально в браузере.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev        # http://localhost:5173
```

Другие команды:

```bash
npm test           # модульные тесты логики (расписание, напоминания, серии, импорт)
npm run typecheck  # проверка типов
npm run build      # сборка в dist/
npm run preview    # просмотр собранной версии
```

Чтобы открыть с телефона в той же сети Wi-Fi: `npm run dev -- --host`.
Системные уведомления работают на `localhost` и на сайтах с HTTPS.

## Что есть в этой версии

- **Мой день** — приветствие, дата, счётчики, прогресс, ближайшее напоминание, список дел по времени, быстрое добавление.
- **Расписание** — занятия в вузе: предмет, тип, аудитория, преподаватель, повтор каждую неделю или через неделю; напоминание за 10 минут с аудиторией; отмена отдельной пары.
- **Лекарства** — название, назначенная дозировка, форма, время приёмов, даты, повторение, заметки; действия «Принял / Отложить / Пропустить»; история и статусы; приостановка приёма.
- **Календарь** — месяц, выбор дня, цветные категории, добавление, перенос, изменение, удаление, повторения (один экземпляр или вся серия).
- **Привычки** — периодичность, цель на день, отметки, история за 14 дней с правкой, текущая и лучшая серия.
- **Статистика** — неделя / месяц: задачи, привычки, подтверждённые приёмы, график по дням.
- **Настройки** — имя, тема, формат времени, первый день недели, уведомления, интервалы, экспорт / импорт, удаление данных.

## Android-приложение

Проект включает Android-оболочку (Capacitor, папка `android/`). В ней уведомления планирует сама система:
они приходят при закрытом приложении и после перезагрузки телефона.

- Первое напоминание — мягкий звук на громкости уведомлений.
- Если ответа нет, через 10 минут (настраивается) приходит повтор: длинный настойчивый сигнал
  на громкости будильника и с усиленной вибрацией. По умолчанию до 3 повторов.
- В уведомлении есть кнопки «Принял», «Отложить», «Пропустить».

### Как получить APK

**Вариант 1 — Android Studio (на своём компьютере).**

1. Установите [Android Studio](https://developer.android.com/studio) и Node.js 20+.
2. В папке проекта: `npm install`, затем `npm run android:sync`.
3. `npm run android:open` — проект откроется в Android Studio. Дождитесь окончания синхронизации Gradle.
4. Подключите телефон по USB (включите «Отладку по USB») и нажмите ▶ Run — приложение установится.
   Либо меню Build → Build APK(s) и перенесите файл `android/app/build/outputs/apk/debug/app-debug.apk` на телефон.

**Вариант 2 — без установки Android Studio, через GitHub.**

1. Создайте репозиторий на GitHub и загрузите в него проект (ветка `main`).
2. Откройте вкладку Actions → «Android APK» — сборка запустится сама.
3. Скачайте артефакт `daymate-debug-apk`, распакуйте и установите `app-debug.apk` на телефон
   (Android попросит разрешить установку из этого источника).

После каждого изменения веб-кода повторяйте `npm run android:sync` перед сборкой.

### При первом запуске на телефоне

1. Настройки → «Системные уведомления» → разрешить.
2. Нажмите «Проверить уведомление»: через 5 секунд придёт обычное, через 15 — громкое.
3. На Xiaomi, Huawei, Samsung и похожих отключите для DayMate экономию заряда, иначе система может глушить уведомления.

## Важно про напоминания

Веб-версия (в браузере) напоминает, только пока DayMate открыт во вкладке. Android-приложение этого ограничения не имеет.
Android хранит расписание на две недели вперёд — открывайте приложение хотя бы раз в две недели.
Подробности — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

DayMate не является медицинским изделием, не предлагает дозировки и не заменяет врача.
